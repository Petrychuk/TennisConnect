# Как форматировать текст статьи (поле Content в админке)

Это поле — обычный текст, но если писать по правилам ниже, сайт автоматически
превратит его в красиво оформленную статью: заголовки, списки, цитаты,
картинки и т.д.

Каждый "блок" (заголовок, абзац, список...) отделяется от следующего блока
**одной пустой строкой**. Это самое важное правило — если забыть пустую
строку, два абзаца слипнутся в один.

---

## 1. Обычный текст (абзац)

Просто пишете текст. Ничего добавлять не нужно.

```
TennisConnect собирает информацию, когда пользователи регистрируются,
создают профиль или пользуются платформой.
```

---

## 2. Заголовки разделов

Есть два способа сделать заголовок — выберите тот, что удобнее.

### Способ А — нумерованные разделы (для Legal / Terms / Privacy)

Просто пишете номер и название раздела заглавными буквами, каждый на
отдельной строке:

```
1. HOW WE COLLECT INFORMATION

Текст этого раздела...

2. HOW WE USE INFORMATION

Текст этого раздела...
```

Важно: если следующая строка после номера — **не** ещё один номер, сайт
поймёт, что это заголовок раздела, а не пункт списка. Все такие заголовки
получают один и тот же аккуратный стиль по всей статье.

### Способ Б — обычные заголовки (для остальных статей)

```
## Заголовок раздела
```
— крупный заголовок.

```
### Подзаголовок
```
— заголовок поменьше, внутри раздела.

---

## 3. Списки

### Маркированный список

Каждый пункт — новая строка, начинается с `•`, `-` или `*` и пробела:

```
• register an account;
• create or edit profiles;
• upload content;
```

### Нумерованный список

Если это **настоящий список** (два и больше пункта подряд, без текста между
ними) — используйте цифры:

```
1. Первый шаг
2. Второй шаг
3. Третий шаг
```

Если же после цифры сразу идёт текст абзаца (а не следующий номер) — это
превратится в заголовок раздела (см. пункт 2, способ А), а не в список.

---

## 4. Цитата

Строка начинается с `>` и пробела:

```
> TennisConnect отвечает только за площадку, а не за действия
> сторонних организаторов.
```

Если цитата занимает несколько строк — каждую тоже начинайте с `> `,
они склеятся в одну цитату.

---

## 5. Разделительная линия

Просто три чёрточки на отдельной строке:

```
---
```

---

## 6. Картинка внутри текста

```
![Подпись к фото](https://адрес-картинки.jpg)
```

- Квадратные скобки `[]` — подпись (можно оставить пустыми: `![]()`— тогда
  подписи не будет).
- Круглые скобки `()` — ссылка на файл (обычно ссылка на уже загруженное
  фото; проще всего сначала загрузить фото где-нибудь и вставить ссылку).
- **Вертикальные (портретные) фото показываются полностью, без обрезки** —
  сайт сам подстраивает высоту под фото.

---

## 7. Жирный текст, курсив, ссылки — внутри любой строки

Работает внутри абзацев, заголовков, цитат и пунктов списка:

| Хотите получить | Пишете |
|---|---|
| **жирный текст** | `**жирный текст**` |
| *курсив* | `*курсив*` |
| [текст со ссылкой](https://example.com) | `[текст со ссылкой](https://example.com)` |

---

## 8. Обложка статьи (Cover)

- Если загружаете **горизонтальное** фото — оно ляжет широким баннером
  сразу под шапкой сайта, во всю ширину экрана, с названием статьи и
  вступлением поверх фото.
- Если загружаете **вертикальное** фото — сайт автоматически покажет его
  в отдельном, более подходящем расположении (фото сбоку, текст рядом),
  чтобы вертикальное фото не обрезалось в узкую полоску.

Ничего дополнительно настраивать не нужно — ориентацию фото сайт определяет
сам.

## Быстрая шпаргалка

```
## Заголовок раздела

Обычный абзац текста. Можно **выделить жирным** или добавить
[ссылку](https://example.com).

> Цитата в один клик.

• Пункт списка
• Ещё один пункт

1. Настоящий список
2. Второй пункт

---

![Подпись к фото](https://ссылка-на-фото.jpg)

1. НАЗВАНИЕ РАЗДЕЛА ЗАГЛАВНЫМИ (для Legal-статей)

Текст раздела...
```
